# 📚 Book Management System

A command-line application developed in Python for managing books.
It allows users to add, search, edit, and remove books, with data stored in a JSON file and displayed using the pandas library.

---

## 🚀 Features

* 📖 Add new books
* 🔍 Search books by title
* ✏️ Edit book information
* ❌ Remove books
* 📋 List all registered books
* 📊 Tabular data visualization using pandas
* 💾 Data persistence with JSON files

---

## 🛠️ Technologies Used

* Python 3
* pandas
* JSON (data storage)
